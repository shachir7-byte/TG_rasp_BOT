# Описание бота «rasp-serv»

## Назначение

Telegram-бот для студентов и преподавателей колледжа.
Показывает расписание занятий по корпусам и группам в удобном формате прямо в чате.

## Возможности

### Для студентов

- **Выбор корпуса и группы** — при первом входе бот предлагает выбрать корпус
  (Мелик-Карамова, Пролетарский, Маяковского, Рабочая, Захарова, 50 лет ВЛКСМ,
  Пыть-Ях), затем группу. Выбор сохраняется; при повторном `/start` показывается
  привычное меню.
- **Расписание на день** — 6 кнопок (Пн–Сб), текущий день выделен маркером `• Пн •`.
- **Расписание на неделю** — кнопка «📆 Неделя», данные группируются по дням.
- **Подсветка текущей пары** — маркер 📍 рядом с парой, которая идёт прямо сейчас.
- **Уведомления** — ежедневная отправка расписания:
  - по времени (08:00 / 08:30 / 09:00);
  - за N часов до первой пары (1 / 2 / 3 ч).
  - Одно уведомление в день на пользователя.

### Для администратора

- 📊 **Статистика** — топ-30 пользователей, количество запросов, последнее действие.
- 📢 **Рассылка** — массовая всем (кроме админов) или адресная (`ID: текст`).
- 🧪 **Диагностика** — статус БД, движков (🟢/🔴), CPU, RAM процесса.
- 🔄 **Сменить движок** — переключение между v1 и v2 с health-check.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню (регистрация + выбор группы при первом входе) |
| `/menu`  | Быстрый доступ к расписанию |

Всё остальное управление — через inline-кнопки.

## Движки расписания

| Ключ | Сайт | Роль | Статус |
|------|------|------|--------|
| `v2` | sielom-web.ru | Основной | Актуальный |
| `v1` | sielom.ru | Запасной | API отдаёт 404 (с ~2026-11) |

Если основной движок не отвечает, бот автоматически пробует запасной (failover).
Данные кэшируются в памяти (TTL по умолчанию — 30 минут).

## Пользовательский сценарий

```
/start → Выбор корпуса → Выбор группы → Меню с днями недели
                                         ├─ Нажатие на день → расписание дня
                                         ├─ «📆 Неделя» → расписание недели
                                         ├─ «⏰ Уведы» → настройка уведомлений
                                         ├─ «🔄 Сменить группу» → выбор корпуса
                                         ├─ «ℹ️ Помощь» → справка
                                         └─ «👑 Админ» → панель (только для ADMIN_ID)
```

## Стек

- Python 3.11+, aiogram 3, aiohttp, aiosqlite
- SQLite (WAL) — хранение пользователей, настроек, статистики
- systemd на Ubuntu (прод), venv

## Деплой

Прод-сервер: Ubuntu, каталог `/opt/rasp-serv`, пользователь `rasp`,
systemd-юнит `rasp-serv.service`. Подробности — в [README.md](README.md).
